# REMOTE_URL_PORT

The remote URL port is not allowed.

Category: `upload`. HTTP 400. Retryable: false.

The default allowed ports are 80 and 443. Add the port to FILEVORA_REMOTE_ALLOWED_PORTS when a local server uses another port.

- allow_port: Set FILEVORA_REMOTE_ALLOWED_PORTS to include this port. (`FILEVORA_REMOTE_ALLOWED_PORTS=80,443`)
